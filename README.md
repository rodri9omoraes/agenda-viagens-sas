# 🚗 Agenda de Viagens - SAS

Sistema desktop desenvolvido em Electron.js para gerenciamento de viagens, motoristas e escalas.

## 🚀 Funcionalidades
- Cadastro, edição e cancelamento de viagens.
- Calendário visual interativo com post-its.
- Controle de férias e folgas de motoristas com alertas inteligentes.
- Geração de imagem (PNG) da pauta do dia para motoristas.
- Dashboard de relatórios com gráficos (Chart.js) de produtividade e destinos.

## 🛠️ Tecnologias
- **Frontend:** HTML5, CSS3, JavaScript (Vanilla)
- **Backend:** Node.js, Express
- **Desktop:** Electron.js
- **Banco de Dados:** SQLite (sql.js)
- **Gráficos:** Chart.js
